# Team Economy 1.0.0 试玩指南：从回收物资到第一局

**先卖一批余料，再给基地添一台能玩的机器。**

Team Economy 把原版物资回收成点数，存进个人或 FTB 队伍钱包，再用来采购、升级和玩实体小游戏。本指南从实际操作讲起：在哪里打开商店、第一台机器花多少、按钮怎么点、奖励记到哪里。制作：**洁柔厨**。

适用环境见下方四版本安装表；玩法说明以 **NeoForge 1.21.1** 为主，1.20.1 的奖池按该版本可用生物调整。下文金额、解锁等级和奖励均为 **1.0.0 默认规则**；服主可以修改部分数值，实际以当前服务器界面为准。

## 游戏内指南：从目录找到操作、概率和配方

安装匹配版本的 **Patchouli**，把「团队经济指南」拿在主手，按右键打开。首次进入会收到一本，也可用书和铁锭无序合成。简体中文、繁体中文、英文随游戏语言切换。

1. **从目录选择主题。** 初次体验先读开局条目，再看经济与升级；想用哪台机器，就进入对应条目。
2. **按顺序翻阅。** 先确认解锁等级和获取方法，再看机身按钮、下注和结算；跳冰、倍率竞猜要特别看继续与提取的区别。
3. **看清概率的含义。** 概率页列出单次事件和中奖条件；跳冰的单步概率以已经到达上一层为前提。连续失败、重开界面或批量开盒都不会提高下一次概率。
4. **翻到合成页。** 配方页展示工作台材料位置。合成得到机器后，仍要满足钱包等级；终端通过商店兑换。

## 生存路线：回收 → 买机 → 开始 → 查看入账

### 1. 打开商店，看看当前钱包

在聊天栏输入：

```text
/teamecon shop
```

这是普通玩家命令，不需要开启作弊，也不需要先合成商店柜体。商店左上方显示当前钱包，右上方显示余额和等级。**全新个人开局**默认领取 **200 点**启动资金，从 **Lv.1** 开始；加入已有队伍时以队伍钱包为准。

点数直接存在钱包里，不占背包格。首次体验先以 **300 点余额**为目标：其中 200 点买机，剩余 100 点留作游玩本金。

### 2. 把多余材料换成点数

切换到「出售」页，**Shift 点击背包中的原版物资**，把它们移入左侧 27 格待售区。先留好工具、食物和近期要用的材料，再核对右侧整批报价，点击 **「出售全部待售物品」**。


<!-- capture-slot: manual-recycling
![27 格待售区和确认出售前的整批报价](images/screenshots/manual-recycling.png)
-->


例如可以准备铁锭、铜锭、煤炭和原木等常见余料，分批放入待售区。收入以当前整批报价为准；达到目标余额就继续下一步。

未出售的物品会在关闭商店时退回。系统不支持回收的物品不会被卖掉；若收入会超过钱包容量，整批不成交。

### 3. 买一台猜大小机，留够首局本金

切到「机器」页，找到 **猜大小机**并购买，默认价格 **200 点**、Lv.1 即可使用。建议先把余额攒到 **300 点**：买机后还剩 **100 点**，可以从一局 20 点开始熟悉操作。

直接用初始的 200 点买机会花完余额，还需要回收物资才能开始游戏。如果只想先试一个操作简单的玩法，也可去「刮卡」页花 **10 点**买幸运数字卡。

| 当前目标 | 购入花费 | 额外保留 | 购买前余额 |
|---|---:|---:|---:|
| 买一张幸运数字卡，按默认 ×1 票面刮开 | 10 | 自行决定 | 至少 10 |
| 买猜大小机并留出第一轮体验预算 | 200 | 100 | 建议 **300** |

买卡时已经支付票价，刮开不再另收一份费用；机器购入后，每局仍需支付所选下注额。

机器还能合成，配方见[常用配方](#recipes)。猜大小机的合成需要石英块，已有点数时直接购买更方便。

### 4. 摆好机器，玩完一局

猜大小机需要预留 **宽 2 × 高 3 × 深 2 格**的空间。放好后站到机器正面，对准机身按钮右键操作：

1. 用下方的金额加减按钮，把下注额调到 **20 点**。
2. 选择「大」或「小」：**1–5 为小，6–10 为大**。
3. 确认金额与选项，再右键 **「下注并开始」**，等待结果。


<!-- capture-slot: manual-hilo
![猜大小机正面的开始、大小选项与金额按钮](images/screenshots/manual-hilo.png)
-->


猜中默认按 **×1.8** 入账，**奖励包含本金**。例如买机后余额 100，下注 20 后余额 80；猜中入账 36，余额变为 **116**，这一局净赚 **16**。猜错则不返奖，余额为 **80**。

结果出现后，可以查看机身的「已入账」提示，再输入 `/teamecon balance` 核对当前余额。至此，回收、购机和第一局的完整流程就走通了。

### 5. 想玩跳冰，就准备第一笔升级费

打开商店「升级」页，选择 **Lv.2**，点击 **「购买等级」**，默认扣除 **1,200 点**。此时解锁史莱姆跳冰的使用权限，机器需要另行获取。


<!-- capture-slot: manual-upgrade
![升级页中的当前等级、升级费用和设备权限](images/screenshots/manual-upgrade.png)
-->


| 第一阶段目标 | 需要准备的点数 |
|---|---:|
| 只升到 Lv.2 | 1,200 |
| 升到 Lv.2，并直接购买史莱姆跳冰机 | 1,200 + 1,500 = **2,700** |
| 买齐后以 20 点玩第一局 | **2,720** |

表中没有计入此前购买猜大小机或其他物品的花费。若自己合成跳冰机，只需准备升级费和游玩本金。**持续回收物资就能升级，不要求通过小游戏赢钱。**

<a id="shop"></a>

## 商店：回收、采购和解锁

自动售货机是两格高的柜体，右键可打开积分商店；`/teamecon shop` 提供同样的基础商店入口。商店共有五页：

| 页面 | 用来做什么 |
|---|---|
| 物品 | 购买符合进度要求的原版物品与附魔书 |
| 出售 | 27 格批量回收，确认整批报价后成交 |
| 机器 | 获取设备及后期无线终端 |
| 刮卡 | 选择卡种、票面倍数并购买 |
| 升级 | 查看和购买下一级钱包权限 |

物品页可以按方块、工具、武器、盔甲、食物、附魔／药水、材料等类别筛选。搜索支持显示名称、完整或部分物品 ID，以及 `#标签`；例如输入 `minecraft:cooked_beef` 查熟牛肉，输入 `#minecraft:logs` 查原木标签。用滚轮或底部箭头翻页，选择商品后按 **1／16／64** 个购买。


<!-- capture-slot: manual-food
![搜索熟牛肉后的商品价格和购买按钮](images/screenshots/manual-food.png)
-->


*默认熟牛肉单价为 32 点。200 点只能买 6 块，商店更适合应急补给；种田、养殖和烹饪仍然有用。*

普通商品购买价至少为基础回收价的两倍，部分物品另有价格下限。物品提示里的回收估价不等于购买价，最终收入还会受到市场需求影响；同类材料共享需求递减，把同一种材料换个形态卖也会影响同组需求。

当前交易范围为**原版物品与原版附魔**。第三方模组物品与附魔不参与买卖；本模组设备、终端和票卡不能回收。默认不出售鞘翅、下界之星等关键战利品，其他进阶商品也可能要求操作玩家先完成相应原版进度。具体价格与规则见[平衡配置指南](平衡配置指南.md)。

<a id="levels"></a>

## 五级成长：权限和机器分开获取

等级属于当前使用的钱包。升级要逐级支付，表中的升级费是**从上一级升到该级的一次费用**；以前解锁的机器仍可继续使用。

| 钱包等级 | 本次升级费 | 新解锁的游戏设备及默认购机价 |
|---|---:|---|
| Lv.1 · 入门 | 初始等级 | 猜大小机：200 |
| Lv.2 · 进阶 | 1,200 | 史莱姆跳冰机：1,500 |
| Lv.3 · 熟练 | 10,000 | 幸运转盘：7,500 |
| Lv.4 · 专家 | 50,000 | 黑红轮盘：30,000 |
| Lv.5 · 大师 | 200,000 | 老虎机：75,000；倍率竞猜机：100,000 |

从 Lv.1 升到 Lv.5 的升级费合计 **261,200 点**，不含机器与终端。即使通过合成、创造模式或其他玩家获得了机器，使用时仍会检查钱包等级。更高等级也会提高早期机器的下注上限；实际额度可在机身的金额设置中查看。

**无线终端**默认需要同时满足 **Lv.5** 和完成原版进度 **「解放末地」**，再花 **100,000 点**兑换。手持右键打开后，可使用商店、批量回收、升级、游戏和购卡功能。使用时仍检查权限；盲盒要去独立盲盒机开启。

## 六种实体游戏怎么操作

### 先给机器留好空间

| 设备 | 预留空间（宽 × 高 × 深） |
|---|---|
| 猜大小机、老虎机、倍率竞猜机 | **2 × 3 × 2** |
| 史莱姆跳冰机 | **3 × 3 × 2** |
| 幸运转盘、黑红轮盘 | **3 × 3 × 3** |
| 自动售货机、盲盒机 | **1 × 2 × 1** |

黑红轮盘的台面较低，仍需按表预留结构空间。正面留出玩家站立和点击的位置，放置位置上方也要有足够空位。

### 通用按钮

机身从上到下可以看到开始区、下注金额、选项和金额调整区。右键 **−100／−10／+10／+100** 改金额，**蹲下右键**使用十倍步长。调整后要单独按「下注并开始」，才会开始一局。

「倍率」按钮用于调整下注金额，按固定基数计算：基数 100 时，×10 得到 1,000；重新选 ×2 得到 200，×1 回到 100。手动加减或直接输入金额会建立新的基数；超出当前额度时不能应用。

### 每种游戏的规则

| 游戏 | 操作与默认结算 |
|---|---|
| 猜大小 | 选大或小，1–5 为小、6–10 为大；猜中 **×1.8** |
| 史莱姆跳冰 | 开始时扣一次本金。每次成功后选择继续跳或**提取并结束**；跌落则本局归零 |
| 幸运转盘 | 调好金额后开始，无需选颜色。灰／绿／蓝／紫／金分别 **×0／1／2／4／10** |
| 黑红轮盘 | 面板选红、黑、绿 0；也可右键台面数字选择单号。红黑猜中 **×2**，单号猜中 **×32**；落在 0 时红黑都不中奖 |
| 老虎机 | 三轴停稳后按图案入账。任意图案的对子 **×1.2**；三枚樱桃／柠檬／橙子／铃铛／星／钻石分别 **×3／4／7／16／40／200** |
| 倍率竞猜 | 开始后倍率从 ×1 上涨，在崩盘前主动**提取并结束**；崩盘则本局归零，默认倍率上限为 ×1,000 |

所有奖励倍率均包含本金，例如下注 100、奖励 ×2，实际入账 200。


<!-- capture-slot: manual-slime
![史莱姆跳冰的当前层数、继续和提取按钮](images/screenshots/manual-slime.png)
-->


跳冰的累计倍率依次为 **×1.2 → 1.5 → 2 → 2.75 → 4 → 6 → 10 → 16 → 25 → 40**。倍率越高，下一跳越难。每次成功后都可以停下来提取，继续跳不会重新扣一份本金。

### 默认事件概率

以下是每次事件的概率。奖金倍数包含本金；没有保底，连续失败不会提高下一次概率。服主自定义后以实际界面和奖池预览为准。

| 机器 | 发生概率与中奖条件 |
|---|---|
| 猜大小机 | 1–10 各有 10%；小 1–5、大 6–10，双方猜中概率各 50% |
| 史莱姆跳冰 | 到达第 1–5 层的单步成功概率约 80%／75%／70.588%／66.667%／63.158%；第 6–10 层约 60%／57.143%／54.545%／52.174%／50%。每个概率都以已经到达上一层为前提 |
| 幸运转盘 | 灰 57.5%、绿 22.5%、蓝 12.5%、紫 5%、金 2.5%；对应 ×0／1／2／4／10 |
| 黑红轮盘 | 红黑、奇偶、大小区间均为 18/37（约 48.65%）；每个单号含绿 0 为 1/37（约 2.70%） |
| 老虎机 | 各轴独立：樱桃 25%、柠檬 25%、橙子 20%、铃铛 15%、星 10%、钻石 5%；对子或三连合计中奖概率 **51.25%**，三钻石为 **0.0125%（1/8,000）**；只支付最高奖项 |
| 倍率竞猜机 | 约 20.32% 开局立即崩盘；从开局存活到 ×2 约 39.8%、×10 约 7.97%、×100 约 0.159%。实际提取由服务器游戏刻确定 |

### 离开机器时，这一局会怎样？

| 正在进行的游戏 | 离开、掉线后的处理 |
|---|---|
| 跳冰 | 离开、断线或机器卸载后自动结算回原钱包；若动画未结束，先完成该次结果再结算 |
| 倍率竞猜 | **只要服务器继续运行，关闭终端、离开机器或断线后仍继续计时，不会自动提取**；提取以服务端收到操作时为准 |
| 猜大小、转盘、轮盘、老虎机 | 已开始的单次游戏按该局结果结算，掉线或拆机不会让这一局重新抽取 |

同一玩家可以让多台实体机器同时运行，每台独立计时、操作和结算；无线终端也有独立的一局。同一台机器仍由当前操作者使用，结束后才能换人。每局先扣款，结算回原出资钱包，离线或机器卸载不会丢失待结算记录。

## 八种刮刮卡：拿在主手，用左键刮开

在商店「刮卡」页购买卡片，把卡拿在**主手**，**左键**打开。按住鼠标左键拖过银色区域，刮开全部区域后自动结算；不需要另按兑奖按钮。

| 卡片 | 解锁等级 | 基础票价 | 看什么结果 |

| 骰子凑七 | Lv.1 | 25 | 同一对骰子是否相加为 7 |
| 水果连线 | Lv.2 | 50 | 一行是否为三个相同水果 |
| 幸运七 | Lv.2 | 100 | 是否找到 7 |
| 宝石寻踪 | Lv.3 | 250 | 是否至少找到三颗钻石 |
| 金币宾果 | Lv.4 | 500 | 金币是否横、竖或斜向连线 |
| 密码宝库 | Lv.4 | 1,000 | 是否匹配三位密码 |
| 皇冠大奖 | Lv.5 | 2,500 | 是否至少找到三顶皇冠 |

购卡时可以提高票面倍数，花费与奖金同步放大。Lv.1～5 的单张票面上限依次为 **100／1,000／10,000／100,000／250,000 点**。购卡前查看实际票面，不要把基础票价当成提高倍数后的花费。

卡片购买时已确定奖项，关闭重开不会重抽。卡可以交给其他玩家，完成刮取的实际持卡者收款；每张卡只结算一次。

## 盲盒：先看奖池，再决定开几盒

盲盒从**独立盲盒机**打开，普通商店与无线终端内没有盲盒页。右键柜体后：

1. 选择物资箱或珍藏箱，打开 **「奖池预览」**，查看当前服务器的奖品和数量。
2. 确认单价与背包空间，选择 **1／10／64** 个，再开启。
3. 切到 **「本次奖品」** 查看实际获得的物品，用箭头或滚轮翻页。

![独立盲盒机的珍藏箱奖池预览](images/screenshots/manual-boxes.png)
-->


| 默认箱种 | 单价 | 特点 |
|---|---:|---|
| 物资箱 | 64 | 日常物资补充 |
| 珍藏箱 | 512 | 更贵的物资奖池，含高价值矿物、附魔金苹果及 43 种友好／中立生物刷怪蛋 |

默认盲盒不含空盒，没有等级或原版进度门槛；空间不足时整批拒绝，不会先扣钱再塞不下。刷怪蛋不能直接购买或回收。盒中物品的回收收入和商店售价不同，开盒后回收不会等额返还箱价。

每个物资箱 64 点，共 11 种奖项，包括两颗钻石（1.8%）和下界合金锭（0.2%）。珍藏箱 512 点，共 54 项，含 16 颗钻石（0.5%）、附魔金苹果（0.5%）、下界合金锭（1%）；43 种刷怪蛋合计 10%，单种约 0.23%–0.24%。涵盖悦灵、村民、流浪商人、嗅探兽、铁傀儡、雪傀儡与原版动物；部分中立生物会反击。

鼠标悬停奖池图标可查看该项的实际概率。每盒独立抽取一次，批量开启不改变单盒概率。高价值奖项可以超过本次箱价，但并不保证每盒都赚。

## 叫上队友，共用一个钱包

客户端与服务端装好 FTB Teams 及其依赖后，通过 **FTB Teams 的队伍界面**创建队伍、邀请好友，并让好友接受邀请。需要加入同一个 FTB 队伍；原版 `/team` 队伍不能代替这一步。

打开 `/teamecon shop` 或输入 `/teamecon balance`，确认当前钱包已经显示队伍名称。此后成员回收所得进入队伍钱包，购买、升级和下注也从这个钱包扣除；设备等级共同使用。

右侧小栏显示队名、当前余额和成员净收支；离线成员仍保留，人数多时自动翻页。这里的**净收支＝回收收入＋游戏奖励－下注－购物－升级－盲盒等消费**，支出会让数字下降，亏损时可以为负。初始资金与管理员设置余额不算成员收入。

队伍资金和个人钱包分开使用。**入队不会把个人余额和个人等级自动并入队伍**，退队后切回个人钱包及原有个人等级。新建队伍后看到余额为 0 时，可以先在队伍状态下回收一批材料；重新登录或反复换队不会补发启动资金。

切换队伍后先查看商店左上的钱包名称，确认当前资金来源。商品的原版进度仍按操作玩家检查，共享钱包不会替代个人冒险进度。

## 常见问题

**没有商店柜体，怎样开始？** 直接输入 `/teamecon shop`。如果想在基地设置固定入口，再合成或购买自动售货机。

**为什么没有再次收到 200 点？** 启动资金有一次性领取记录，已经存在的钱包不会重复发放；新建队伍也不会把个人启动资金复制过去。切换队伍后先核对当前钱包，再通过回收物资积攒点数。

**指南书右键打不开？** 确认两端均安装了匹配游戏版本与加载器的 Patchouli；Forge 1.21.1 请先使用网页版指南。没有安装时，商店与小游戏仍可使用。

**同样的材料为什么越卖越便宜？** 同材料组共享市场需求递减，实际收入以出售页整批报价为准。

**有钱却不能买物品或玩机器？** 查看界面的锁定原因：可能缺少原版进度或钱包等级，也可能商品不在当前交易范围。先区分「已获得机器」和「已解锁使用权限」。

**为什么找不到第三方模组物品？** 1.0.0 暂不支持买卖第三方物品和附魔。有关服务器价格、白名单等设置的边界见[配置指南](平衡配置指南.md)。

**刮刮卡为什么右键没反应？** 请拿在主手，用左键打开；刮开全部区域后自动结算。

**创造模式取出的刮刮卡为什么不能用？** 有效卡片需要从商店购买。快速试玩时先设置钱包余额，再到「刮卡」页购卡；直接从创造物品栏取出的卡无法正常刮取兑奖。

**机器放不下或点不到按钮？** 按上文表格清出完整空间，再站到机身正面，对准按钮右键。机器显示占用中时，需要等当前一局结束。

## 快速试玩：在允许作弊的世界体验全部设备

想先看机器外观、按钮和结算，可以新建一个**允许作弊的单人世界**。服务器中由具备 **OP 权限等级 2** 的玩家操作以下命令。

### 1. 领取设备和演示资金

按行输入：

```text
/teamecon admin kit
/teamecon admin unlock
/teamecon admin balance 1000000
/teamecon shop
```

第一条命令给予**六种游戏机、自动售货机和盲盒机**；第二条将当前钱包设为 Lv.5，并豁免操作者在团队经济中的原版进度门槛，不会授予原版进度。第三条将**当前钱包**余额设为 1,000,000，在队伍中操作时影响队伍钱包。

### 2. 摆放机器与选择成长路线

`admin unlock` 已解锁全部设备，无需再支付升级费。若想体验正常成长流程，先执行 `/teamecon admin bypass false` 恢复进度门槛，再执行 `/teamecon admin level 1`，然后在「升级」页依次购买 **Lv.2、Lv.3、Lv.4、Lv.5**；默认共花费 **261,200 点**。

等级指令作用于当前钱包，队伍成员共享其变化。按[尺寸表](#games)预留空位，放置所有设备，并在机身正面留出通道。

### 3. 按这个顺序试一遍

1. 猜大小：调到 20 点，选「小」，按「下注并开始」，看数字与入账提示。
2. 跳冰：开始一局，成功后按「提取并结束」；若跌落，可再开一局熟悉按钮。
3. 幸运转盘、黑红轮盘、老虎机：分别开始一局，观察不同的选择方式和结算结果。
4. 倍率竞猜：开始后观察倍率上涨，主动提取。关掉界面或离开不会自动提取。
5. 刮刮卡：去商店「刮卡」页**实际购买**一张，主手左键打开并刮完。
6. 盲盒：右键盲盒机，选箱种、看「奖池预览」，先开 1 盒，再看「本次奖品」。

小游戏存在输赢，这条路线用于认识操作。无线终端还要求操作玩家完成「解放末地」，`admin unlock` 只让团队经济跳过这项检查，不会授予该进度；仅设置余额或执行 `admin level 5` 则不会。队伍体验按[组队步骤](#teams)另外创建或加入 FTB 队伍。

### 服主管理命令速查

| 管理命令 | 用途 |
|---|---|
| `/teamecon admin kit` | 获取六种游戏机、自动售货机与盲盒机 |
| `/teamecon admin balance 1000000` | 将**当前使用的钱包**余额设为 1,000,000；在队伍中会作用于队伍钱包 |
| `/teamecon admin unlock [玩家]` | 当前钱包免费设为 Lv.5，目标玩家豁免本模组的进度门槛；省略玩家为自己 |
| `/teamecon admin level <1–5> [玩家]` | 设置目标玩家当前钱包等级，保留个人进度与豁免状态 |
| `/teamecon admin bypass <true/false> [玩家]` | 开启／关闭目标玩家的本模组进度门槛豁免，保留钱包等级 |
| `/teamecon admin advancements [玩家]` | 等同于 `bypass true`，原版进度保持不变 |
| `/teamecon admin status [玩家]` | 查看等级、余额与本模组进度豁免状态 |
| `/teamecon admin reload` | 重载本模组 JSON 配置 |

豁免按玩家保存，重登后仍有效，不自动扩散给队友；钱包等级仍按个人／队伍钱包共享。它只跳过进度门槛，购买仍收费，禁售物品和交易范围仍按服务器规则处理。

JSON 配置修改后可用 `admin reload` 重载。配置文件位置与可调整范围见[平衡配置指南](平衡配置指南.md)。
